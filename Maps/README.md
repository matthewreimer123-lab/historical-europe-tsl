# WorldBuilder map placeholder

Create the map in Civilization V SDK WorldBuilder and save it here as:

`HistoricalEurope.Civ5Map`

Required initial settings:

- Width: 120
- Height: 80
- World wrap: off
- Scenario players: none
- Fixed starting positions: none

Do not rename the final file without also updating `HistoricalEuropeTSL.modinfo`.
